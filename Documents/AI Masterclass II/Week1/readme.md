# Calling API (CoinMarketCAP API)

An application that uses a price API by CoinMarketCap to retrieve cryptocurrency prices

## What It Does

- Retrieves JSON data to include:
	- the cryptocurrency ID and the price
	- status

## Features:
	- API integration
	- Error handling
	- JSON response processing

## Setup

```bash
pip install -r requirements.txt
```

## Usage

```python
apis_1.py

```
